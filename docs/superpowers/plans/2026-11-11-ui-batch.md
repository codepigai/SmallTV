# 操作改进批次实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 落地 v1.1 后的 5 项操作改进：延迟毫秒绿色、首页画廊模式、播放页键位重构、订阅管理双栏改版、设置页（回看已砍）。

**Architecture:** 全部在传统 Views + Kotlin 单模块内完成；新交互的可测逻辑（设置存取、标签/文案纯函数）抽到 `ui` 包顶层函数走 JVM 测试；Room 升一版加列（手写迁移，禁破坏性重建）；播放页复用多屏的 `ChannelDrawer`/`EpgPanel`（构造签名相同）。

**Tech Stack:** Kotlin、media3 1.2.1、Room、RecyclerView、Glide、SharedPreferences。不新增任何依赖。

**Spec:** `docs/superpowers/specs/2026-11-11-ui-batch-design.md`（含 9 条裁决清单与砍回看依据，必读）

## Global Constraints

- minSdk 23 / target 34：API 28+ 方法（`Handler.hasCallbacks` 等）不可用。
- **不新增依赖**（无 Robolectric/androidTest——Room 迁移正确性只能真机覆盖安装验收）。
- **不 bump versionCode/versionName**（用户铁律）；版本号仅只读展示。
- 测试命令（PowerShell，每条新 shell 都要重设）：
  `$env:JAVA_HOME='D:\app\bigtext\tools\jdk17'; .\gradlew.bat testDebugUnitTest --offline` → 期望 BUILD SUCCESSFUL，**现有 40 条测试必须保持全绿**。
- 编译验证：`.\gradlew.bat assembleDebug --offline` → BUILD SUCCESSFUL。
- commit 用中文 `[feat]`/`[test]` 前缀，末尾空行后加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`；`git add` 只加显式路径，**永不 `git add .`**。
- 绿色统一 `0xFF4CAF50`；节目名/分组名等次要文字保持 `#8899BB`。
